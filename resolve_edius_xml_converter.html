Resolve → EDIUS
XML変換ツール

DaVinci Resolveから書き出したXMLを、29.97fps（30/1.001）向けのXMLに変換します。ファイルはブラウザ内で処理し、外部へ送信しません。

2. 変換ルール

  • レート：XML内の timebase=60 を 30 に変更し、NTSCフラグは維持します。
  • フレーム値：duration / start / end / in / out / frame の数値を2分の1に丸めます。
  • 素材パス：変更しません。読み込み先PCで素材の再リンクが必要な場合があります。

※ 試作版です。元XMLのフレーム数を機械的に半分にする方式のため、素材のイン／アウト、音声同期、重ね合わせ、端数フレームの扱いが意図どおりかはEDIUSで確認してください。元ファイルは上書きしません。

オフラインで動作する単一HTMLです。Chrome / Edge / Safariなど、File APIとXML DOMに対応したブラウザで開いてください。
